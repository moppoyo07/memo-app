# 貸し借り帳（PWA ＋ Googleスプレッドシート）

- 画面（PWA）：GitHub Pages に置く → `index.html` `app.js` `style.css` `config.js` `manifest.webmanifest` `sw.js` `icons/`
- 保存・計算：自分のドライブのスプレッドシート ＋ Apps Script → `gas/Code.gs`
- スタッフはスプレッドシートを見られません。キー付きリンクがないと何も見られません

## 1. スプレッドシート側（保存・計算）
1. 自分のGoogleドライブで新しいスプレッドシートを作る
2. 「拡張機能」→「Apps Script」→ 中身を消して `gas/Code.gs` を貼り付けて保存
3. 関数 `setup` を選んで「実行」→ 承認画面で許可
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 表示される **ウェブアプリのURL（…/exec）** をコピー

## 2. GitHub側（アプリの画面）
1. `config.js` の `apiUrl` を、上でコピーしたURLに書き換える
2. GitHubで新しいリポジトリを作る（Public）
3. 「Add file」→「Upload files」で、`gas` フォルダ以外を全部アップロード（`icons` フォルダも）
4. 「Settings」→「Pages」→ Branch を `main` / `(root)` にして Save
5. 1〜2分で `https://あなたのID.github.io/リポジトリ名/` が公開される

## 3. リンクを作る
1. スプレッドシートの「設定」シートで、名前・与信枠・**アプリのURL**（上のGitHub PagesのURL）を書く
2. Apps Script で関数 `showLinks` を実行 → ログに **自分用** と **相手用** のリンクが出る
3. 自分用リンクをスマホで開いて「ホーム画面に追加」
4. 相手用リンクをスタッフに送る（スタッフもホーム画面に追加）

※ ホーム画面から開いたときに「リンクを貼り付けてください」と出たら、受け取ったリンクを一度貼れば次から出なくなります。

## 見える範囲
| | 自分 | スタッフ |
|---|---|---|
| 残高 | ○ | ○ |
| 貸した日・金額 | ○ | ○（「借りた」と表示） |
| 返済の日・金額・確認状況 | ○ | ○ |
| メモ | ○ | × |
| 与信枠 | ○ | × |
| 登録・取消 | ○ | × |
| 貸付・返済の「確認しました」 | 確認されたか見える | ○ |

※ 残高に入るのは、スタッフが「確認しました」を押した記録だけです。未確認の記録は「確認待ち」として別に表示されます。内容が違うときは直接話して、自分が取消して登録し直します。

## 困ったとき
- **相手用リンクを止めたい**：`resetStaffKey` を実行（新しいリンクがログに出ます）
- **Code.gs を直したとき**：「デプロイ」→「デプロイを管理」→ 鉛筆 →「新しいバージョン」→ デプロイ（URLは変わりません）
- **画面のファイルを直したとき**：GitHubに上書きアップロード。反映されないときは `sw.js` の `kashikari-v1` を `v2` に変える
